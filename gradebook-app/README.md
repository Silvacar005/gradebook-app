Student Grade Management System:

# Overview:
This project is a desktop application built using *Python* and *Tkinter* that allows users to manage student information, record grades, and calculate averages. It demonstrates key object-oriented programming concepts such as *encapsulation*, *inheritance (via built-in structures)*, *polymorphism*, and uses a clean, modular design with separate classes for the data model and user interface.

The program loads and saves all student data automatically in `gradebook_data.json`, making it persistent across sessions.


# Features:
- Add students (ID + Name)
- Delete students
- Record grades for any course
- Automatically calculate:
  - Individual student averages
  - Letter grades
  - Class average
- Persistent storage using JSON
- Graphical interface using Tkinter
- Input validation and error handling

# Instalation:

# Example Usage
- Open the app  
- Enter Student ID → Enter Name → Add Student  
- Enter course + numeric grade → Record Grade  
- Click “Show Class Average” to see the average of all students  


The listbox updates automatically, showing every student and their courses.
